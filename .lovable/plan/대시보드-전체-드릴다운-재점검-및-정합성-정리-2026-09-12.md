# 대시보드 전체 드릴다운 재점검 및 정합성 정리

대시보드의 모든 숫자를 클릭 가능하게 만들고, 클릭해서 열리는 목록의 건수가 카드에 적힌 숫자와 정확히 일치하도록 맞춥니다.

## 지금 확인된 문제

1. **부문별 숫자와 목록 건수 불일치**
   카드의 부문별 집계는 "파일 구분 또는 담당부서"가 일치하는 행을 세는데, 클릭하면 담당부서만으로 걸러진 목록이 열립니다. 인허가처럼 두 값이 다른 행에서 숫자와 목록이 어긋납니다.

2. **완료 기준이 두 가지**
   카드의 "완료"는 100% 이상만, 목록의 "완료" 상태는 99.5% 이상을 완료로 봅니다. 99.5~100% 구간의 행 때문에 숫자가 달라집니다.

3. **담당자별 클릭이 전체 검색으로 열림**
   담당자별 막대를 누르면 이름이 통합 검색어로 들어가, 다른 칸에 같은 글자가 있는 행까지 함께 잡힙니다. 담당자 전용 필터로 열려야 합니다.

4. **T&C 카드의 Pass 숫자가 Fail 목록으로 이동**
   T2 판정 카드에서 Pass 수치를 눌러도 Fail만 걸러진 목록이 열립니다.

5. **T&C 단계 숫자와 목록이 다른 대상**
   카드 숫자는 수량(Qty) 합계인데, 열리는 목록은 단계 조건 없이 공종만 걸린 전체 항목입니다. 단계·완료 여부 조건이 함께 전달되어야 합니다.

6. **클릭이 아예 없는 항목**
   마일스톤 카드의 "초과", 계획·실적 카드의 평균 수치 일부, T&C 카드의 "전체 Qty"와 "계획" 값, 진도 추이 표의 각 행, 출면 카드 내부 세부 수치는 현재 클릭해도 아무 일이 없습니다.

## 할 일

### 1) 숫자 기준 통일
- 부문별 집계와 드릴다운이 같은 규칙(파일 구분 또는 담당부서)을 쓰도록 목록 쪽에 같은 조건을 전달합니다.
- 완료 판정을 목록과 동일한 기준으로 통일합니다.
- 지연·계획·실적 모수(진도 값이 있는 행만/전체 행)를 카드와 목록에서 동일하게 맞춥니다.

### 2) 드릴다운 전달값 확장
- 담당자, 파일 구분(공종), 진도 보유 여부, 지연 여부를 URL로 전달할 수 있게 목록 화면의 필터 항목을 넓힙니다.
- T&C는 단계 + 완료/잔여/지연/Pass/Fail 조건을 함께 전달합니다(목록 화면에 이미 있는 기능을 연결).

### 3) 전 항목 클릭 가능화
- 총 활동, 완료, 부문별 계획·실적·차이
- 계획 대비 실적(전체/부문별 계획·실적·차이)
- 지연(전체/부문별)
- 마일스톤 카드: 총건수, 평균, 지연, 초과, 계획·실적·차이
- T&C 카드: 단계별 실적·계획·전체 Qty, 공종별 값, Pass/Fail
- 진도 리스크 분석: 진도 막대, 리스크 행(이미 동작하나 위 기준 통일 반영)
- 진도 추이 표: 각 기록일 행 클릭 시 해당 기준일 목록으로 이동
- 출면 카드: 전체 카드 외에 내부 수치도 출면 현황의 해당 항목으로 이동
- 차이(gap) 같은 파생값은 클릭 시 계산 근거가 되는 목록(계획 또는 실적)으로 이동하고, 의미가 없는 값은 클릭 대상에서 제외하고 그대로 둡니다.

### 4) 검증
- 주요 카드 각각에 대해 화면 숫자와 클릭 후 목록 건수가 같은지 실제 데이터로 대조하고, 어긋나면 기준을 맞춥니다.
- 자동 브라우저 점검으로 각 링크가 의도한 필터로 열리는지 확인합니다.

## 기술 메모

- `src/lib/list-search.ts`: `mgr`, `slot`, `hasProgress`, `late` 파라미터 추가 및 `toInitial` 확장.
- `src/components/schedule-table.tsx`: `TableInitial`에 `mgr` 추가, `slot`/`hasProgress` 사전 필터 지원.
- `src/routes/_authenticated/dashboard.tsx`: `bySlot`/`byMs` 집계 기준과 `Drill` search 동기화, 미링크 수치 전부 `Drill` 처리, `TrendCard` 행 링크 추가.
- `src/components/dashboard/progress-risk-analysis.tsx`: `searchFor`의 `mgr` 분기 수정, T&C는 `stage`+`cell` 포함해 `/tc/list`로 이동.
- `isDone`(>=1)과 `stOf`(>=0.995) 기준을 하나로 정리.
- T&C 카드 수치는 Qty 기준임을 카드에 명시하고, 목록은 동일 대상 항목이 뜨도록 단계 조건을 전달.
