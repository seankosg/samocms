# HMMME 통합 공정 관리(Rev.2) 기능을 현재 앱에 이식

첨부한 HTML은 브라우저 한 파일 안에서 동작하는 공정 관리 도구입니다. 상단 탭 7개(대시보드 · 네트워크 · 지연 리스트 · 공정리스트 · MECH T&C · ELEC T&C · T&C List), 엑셀 드래그 업로드, 기준일 설정, 통합 엑셀 다운로드로 구성되어 있습니다. 이 기능과 화면 구성을 현재 앱으로 옮기되, 탭 대신 **왼쪽 사이드바 메뉴**로 재구성하고, 데이터는 브라우저 저장 대신 **클라우드 데이터베이스**에 저장해 여러 사람이 같은 최신 자료를 보도록 만듭니다.

현재 앱에는 공정 데이터 표(838건)와 간단한 KPI 화면, 엑셀 임포트만 있습니다. T&C(시운전) 관련 자료를 담을 곳은 아직 없습니다.

## 1) 화면 구조 — 사이드바 메뉴

```text
┌──────────────┬──────────────────────────────────────┐
│ SAMO / HMMME │ 상단바: 기준일 · 총 건수 · Rev · 내보내기 │
│ 대시보드      ├──────────────────────────────────────┤
│ 네트워크      │                                      │
│ 지연 리스트   │        선택한 메뉴 화면                │
│ 공정리스트    │                                      │
│ ── T&C ──    │                                      │
│ MECH T&C     │                                      │
│ ELEC T&C     │                                      │
│ T&C List     │                                      │
│ 데이터 업로드 │                                      │
└──────────────┴──────────────────────────────────────┘
```

- 각 메뉴는 고유 주소를 가져 북마크·공유가 가능하고, 접기/펼치기가 되는 사이드바로 만듭니다.
- 상단바에는 원본과 동일하게 기준일 설정(직접 지정/자동 복귀), 전체 건수, Rev 표기, 통합 엑셀 다운로드 버튼을 둡니다.
- 원본의 "HTML 저장 / 초기화"는 클라우드 저장 방식과 맞지 않으므로 "통합 엑셀 다운로드"와 "공종별 데이터 초기화"로 대체합니다.

## 2) 데이터 업로드 화면

- 엑셀 드래그&드롭 영역(여러 개 동시), 파일명에서 공종(Arch·Elec·Mech·Int·Permit)과 기준일·Rev 자동 인식.
- 공종별 카드에 최신 반영일·행수를 표시하고, 다른 공종보다 오래된 파일은 경고색으로 표시(원본의 stale 표시).
- MECH T&C · ELEC T&C 엑셀도 같은 자리에서 업로드하며, T&C 시트는 자동 판별해 별도 데이터로 저장합니다.
- 업로드 시 해당 공종 데이터만 교체하고, T&C의 수기 입력값(메모·수동 수량)은 기존 값을 새 자료에 이어 붙입니다.

## 3) 대시보드

- 상단 KPI 3장: 총 활동(완료 건수·비율 막대), 계획 대비 실적(공종별 계획/실적/차이 표 포함), 지연(공종별 지연 건수 막대).
- MEP T&C 현황 4장: T1 · Report · T2 · Status(Pass/Fail), 좌측 합계 + 우측 공종별 내역.
- 마일스톤 M1~M8 카드: 목표일, 명칭, 평균 실적 막대, 총건수·지연·초과·D-day, 계획/실적/차이 수치.
- 부서별 진도 표, 건물별 지연 상위, 협력사별 지연 표.

## 4) 네트워크 화면

원본의 선후행 네트워크 다이어그램을 그대로 옮깁니다.

- 가로 시간축(종료일 기준) 위에 활동 노드를 배치, 선행-후행 연결선 표시.
- 확대/축소(−, %, +, 100%, 화면맞춤), 상단 시간축 고정 스크롤.
- 보기 전환: 네트워크 보기 ↔ 건물·룸 보기.
- 필터: 구분 칩(전체·건설·인허가·생산설비), 부서, 마일스톤, 건물, 지연만 보기, 필터 해제.
- 노드 클릭 시 선후행 체인 강조 + 하단 상세 목록 드로어, 대상 없는 선행 참조 경고 박스.

## 5) 지연 리스트 · 공정리스트

- 지연 리스트: 부서·건물·마일스톤·검색 필터가 붙은 지연 전용 표.
- 공정리스트: 현재 앱의 표를 원본 수준으로 확장(정렬 가능한 열 머리글, 진도 막대, 상태색, 페이지 이동, 현재 필터 결과 엑셀 내보내기).

## 6) T&C 화면 3종

- **MECH T&C / ELEC T&C**: 건물별 서브탭, 좌측 요약 KPI, 중앙 단계별(T0 · T1 · Report · RFI · T2 · Response) 집계표, 우측 상세. 수동 입력 칸은 편집 모드에서만 수정 가능하고 저장하면 모두에게 공유됩니다.
- **T&C List**: 전체 장비 목록을 단계별 계획/실적/잔여 열로 보는 넓은 표(열 그룹 색상, 머리글 고정, 조건부 색상, 엑셀 내보내기).

## 7) Lovable 앱의 장점 살리기

- 데이터가 클라우드에 저장되어 파일을 주고받지 않아도 팀 전체가 같은 최신 현황을 봅니다.
- 각 화면이 고유 주소를 가져 특정 필터 상태를 그대로 공유할 수 있습니다.
- 업로드 이력(공종·기준일·Rev·행수)이 남아 언제 무엇이 갱신됐는지 추적됩니다.
- 화면 폭에 맞춰 사이드바와 표가 자연스럽게 반응합니다.

## 기술 메모

- 라우팅: 사이드바 레이아웃 route 하나 + 하위 route(`/dashboard`, `/network`, `/delays`, `/schedule`, `/tc/mech`, `/tc/elec`, `/tc/list`, `/upload`). 기존 `/`는 대시보드로, `/raw-data`는 `/schedule`로 리다이렉트해 기존 링크 유지. shadcn `sidebar` 컴포넌트 사용.
- 데이터베이스: 기존 `public.activities` 유지 + 신규 `tc_items`(공종·건물·그룹·품목·기기·수량·공급사·단계별 계획/실적/완료수량/잔여, status, docref), `tc_manual`(행 키별 수기 입력·메모), `import_batches`(공종·파일명·기준일·Rev·행수·업로드시각), `app_settings`(기준일 override). 모든 신규 테이블에 GRANT + RLS(익명 읽기 / 쓰기는 서버 함수 경유) 적용.
- 파싱: 기존 `src/lib/import-schedule.ts` 확장 + `tc-parse.ts` 신설(T&C 워크북 판별, 단계 마커 탐색, 요약행 파싱). 저장은 `createServerFn`.
- 계산 로직: HTML의 `isLate`/`isDone`/마일스톤 계산/`tcStageProgress`/네트워크 모델(`buildModel`·`chainOf`·레인 배치)을 순수 TS 모듈로 이식해 화면과 분리.
- 네트워크 다이어그램은 원본과 동일하게 SVG 직접 렌더(가상 스크롤 없이 838 노드 수준은 충분). 확대율·필터는 URL 검색 파라미터로 보존.
- 엑셀 입출력은 이미 설치된 `xlsx` 사용, 색상 토큰은 원본 팔레트(#1f4e79 계열)를 디자인 토큰으로 정의.

## 진행 방식

1단계 사이드바 골격 + 기존 화면 이전, 2단계 대시보드/지연/공정리스트 완성, 3단계 T&C 데이터 구조와 3개 화면, 4단계 네트워크 다이어그램, 5단계 업로드·기준일·내보내기 마무리 순으로 진행합니다.
