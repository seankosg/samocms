# 발주처 네트워크 건물 필터 별칭 통합

## 변경 내용
- 발주처 네트워크의 건물 풀다운 목록을 공통 건물명 표준화 함수로 한 번 더 정규화합니다.
- `C.C`와 `Consolidation Center`, `C.C.C`와 `Complex Cultural Center`, `M.G.`·`MG`와 `Main Gate`가 각각 하나의 옵션으로 표시되게 합니다.
- 선택한 표준 건물명이 네트워크 노드 필터와 상세 화면에도 동일하게 적용되도록 맞춥니다.
- 업로드 원본과 데이터베이스 값은 변경하지 않습니다.

## 확인
- 풀다운에 별칭 중복이 없는지 확인합니다.
- 표준 건물명 선택 시 해당 별칭의 공정이 모두 표시되는지 확인합니다.
- 타입 검사와 빌드 상태를 확인합니다.
