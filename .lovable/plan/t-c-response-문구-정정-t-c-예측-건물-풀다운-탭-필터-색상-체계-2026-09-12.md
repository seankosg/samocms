# T&C Response 문구 정정 · T&C 예측 건물 풀다운 · 탭/필터 색상 체계

## 1) Response 표기 정정

현재 앱 곳곳에서 T&C 6단계 중 `Response`를 "코멘트 대응"으로 표기하고 있습니다.
실제 의미는 **기술회사 회신**이므로 모든 표기를 바꿉니다.

- T&C 단계 라벨: `코멘트 대응` → `기술회사 회신`
- 적용 위치: T&C 화면·리스트·진행 매트릭스·대시보드 T&C 단계 카드 등 라벨을 쓰는 모든 곳
- `Response`라는 영문 단계 키 자체는 그대로 둡니다(데이터·필터 값 변경 없음)

## 2) T&C 예측의 단계 표기

T&C 예측 탭에서는 단계 버튼을 한국어 설명 없이 **`T0` · `T1` · `T2` · `Response`** 그대로 표시합니다.
`전체(4단계 합산)` 버튼은 유지합니다.

## 3) T&C 예측의 건물 선택을 풀다운으로

건물 버튼이 한 줄에 너무 많이 나열되어 어수선하므로,
건물은 **드롭다운(Select)** 으로 바꿉니다.

- `전체 건물`을 기본값으로 하고, 선택한 팀(전체/MECH/ELEC)에 해당하는 건물만 목록에 표시
- 팀을 바꾸면 건물 선택은 `전체 건물`로 초기화(현재 동작 유지)
- 단계·팀은 지금처럼 버튼형 유지

## 4) 앱 전체 탭·필터 색상 구분

사용자가 "탭"과 "필터"를 한눈에 구분하도록, 두 요소에 **서로 다른 고유 배경색**을 부여합니다.

- **탭**: 파랑 계열 — 기본은 옅은 배경, 선택 시 진한 배경 + 흰 글자
- **필터**: 호박(amber) 계열 — 기본은 옅은 배경, 선택 시 진한 배경 + 흰 글자
- 선택되지 않은 항목도 배경이 옅게 깔려 "누를 수 있는 것"임이 보이도록 합니다
- 적용 대상 화면: 대시보드(진행도 예측, 지연 리스크 분석), 공정·지연·T&C 리스트의 필터 칩,
  T&C 진행, 출면 현황·추이·검증 대조, 출면 관리 설정, 안전 리포트 등 탭·필터가 있는 모든 화면
- 다크 모드에서도 대비가 유지되도록 색을 함께 정의합니다

## 기술 사항

- 라벨 상수는 `src/lib/tc-model.ts`(`TC_STAGE_LABEL`), `src/lib/tc-forecast.ts`(`TC_F_STAGE_LABEL`),
  `src/routes/_authenticated/dashboard.tsx`의 단계 카드 정의에서 수정
- T&C 예측 단계 라벨은 예측 전용 상수만 `T0/T1/T2/Response` 원문으로 변경(다른 화면 라벨과 분리)
- 건물 선택은 기존 `@/components/ui/select` 사용, 상태(`tcBldg`)·초기화 로직은 그대로
- 색상은 `src/styles.css`에 `--color-tab-*`, `--color-filter-*` 토큰을 `@theme inline`으로 추가하고,
  `.ui-tab` / `.ui-filter` 성격의 공용 클래스로 적용해 화면별 하드코딩을 피함
- 기능·집계 로직 변경 없음(표시 문구와 스타일, 건물 선택 UI만 변경)
