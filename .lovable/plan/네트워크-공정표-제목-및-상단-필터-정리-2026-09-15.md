# 네트워크 공정표 제목 및 상단 필터 정리

## 확인 결과
- 일반 네트워크 화면의 제목은 현재 `네트워크`이며, 사이드바 명칭은 이미 `네트워크 공정표`입니다.
- 현재 데이터에서 `생산설비(발주처)`와 `발주처만`은 모두 같은 26개 항목을 표시합니다. 따라서 두 필터는 현재 기준으로 완전히 중복됩니다.
- 두 개의 `전체` 버튼은 각각 공정 분류와 업역 범위를 초기화하므로 기능은 다르지만, 같은 이름 때문에 중복처럼 보입니다.
- `발주처 네트워크` 화면에서는 보기 방식이 고정되어 있어 `건물·룸 보기` 전환이 실제 화면을 바꾸지 않습니다.
- 같은 화면의 단독 `전체` 공정 분류 버튼과 `발주처 연관만` 범위도 이미 표시 대상 전체와 같아 의미가 중복됩니다.

## 변경 계획
1. 일반 네트워크 페이지 제목을 `네트워크 공정표`로 변경하고 브라우저 제목과 공유 제목도 같은 명칭으로 맞춥니다.
2. 일반 네트워크 상단에서 중복되는 `발주처만` 버튼을 삭제합니다.
   - `생산설비(발주처)`는 공정 분류 필터로 유지합니다.
   - 업역 범위는 `전체 업역 / 당사만 / 발주처 연관만`으로 정리합니다.
3. 첫 번째 `전체`는 `전체 공정`, 두 번째 `전체`는 `전체 업역`으로 바꿔 각 필터의 목적을 명확히 합니다.
4. `필터 해제`가 공정·부서·마일스톤·건물·지연뿐 아니라 업역 범위까지 초기화하도록 맞춥니다. `선행 영향 반영`은 표시 옵션이므로 유지합니다.
5. 발주처 네트워크 화면에서는 작동하지 않는 `건물·룸 보기` 전환과 의미 없는 단독 `전체 공정` 버튼을 숨깁니다. 업역 범위의 `발주처 연관만`도 제거하고 `전체 업역 / 발주처만 / 당사만`만 제공합니다.
6. 두 네트워크 화면에서 필터별 결과 수와 전환 동작을 확인하고, 모바일에서도 버튼과 선택창이 겹치지 않는지 검증합니다.

## 유지 항목
- 확대·축소, `100%`, `화면맞춤`은 각각 배율 조정·기본 배율 복귀·화면 폭 맞춤으로 역할이 달라 유지합니다.
- 부서·마일스톤·건물·지연 필터와 `선행 영향 반영`은 서로 다른 조건이므로 유지합니다.
- 발주처 전용 네트워크 페이지와 일반 네트워크의 `발주처 연관만` 기능은 유지합니다.

## 기술 사항
- 대상: `src/routes/_authenticated/network.tsx`, `src/components/network-view.tsx`
- `forceMode="owner"` 여부에 따라 불필요한 보기/분류/범위 제어를 조건부로 제외합니다.
- URL에 기존 `scope=owner`가 남아 있어도 안전하게 기본 범위로 정규화해 빈 화면이나 잘못된 선택 상태를 방지합니다.
