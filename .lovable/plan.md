# 모바일/태블릿 레이아웃 최적화

현재 앱은 데스크톱 폭(1280px 이상)을 전제로 만들어져 있습니다. 휴대폰(약 390~430px)과 태블릿(약 768~1024px)에서 확인되는 문제와 개선안입니다.

## 확인된 문제

1. **휴대폰에서 메뉴가 아예 사라짐** — 사이드바가 작은 화면에서 숨겨지도록 되어 있어, 폰에서는 페이지 이동 수단이 없습니다. (가장 시급)
2. **상단 바가 좁은 화면에서 넘침** — 기준일 표시·행수 배지·통합 엑셀·New Version 버튼이 한 줄에 몰려 두 줄로 깨집니다.
3. **표가 화면 밖으로 나감** — 공정리스트(최소 1980px), T&C(1500px), 오늘의 주요작업(1000px/820px) 표가 폰에서 좌우로 크게 밀립니다.
4. **대시보드 카드 내부 표가 눌림** — 카드 좌측 큰 숫자 + 우측 팀별 표 구조가 폰에서 숫자가 겹칩니다.
5. **네트워크 상세 패널이 화면 전체를 덮음** — 폰에서 닫기 동작이 불편하고, 시간축 차트 자체가 폰 조작에 맞지 않습니다.
6. **T&C Progress 필터 줄과 매트릭스** — 필터 요소가 많아 폰에서 세 줄 이상 차지하고, 매트릭스 고정 열이 화면 절반을 먹습니다.
7. **터치 대상 크기** — 표 안 필터 버튼·인라인 편집 셀 등이 손가락으로 누르기에 작습니다.

## 개선 방향

### 1) 내비게이션 (필수)
- 휴대폰에서는 상단 바의 메뉴 버튼이 왼쪽에서 밀려 나오는 서랍형 메뉴를 열도록 변경. 항목 선택 시 자동으로 닫힘.
- 태블릿에서는 아이콘만 있는 좁은 사이드바를 기본값으로, 필요 시 펼침.
- 데스크톱 동작은 지금 그대로 유지.

### 2) 상단 바
- 폰에서는 로고 + 기준일(간략 표시) + 더보기 메뉴만 노출. 통합 엑셀·행수·New Version은 더보기 안으로 이동.
- 기준일 설정 팝업은 폰에서 화면 하단 시트 형태로 표시.

### 3) 표 화면 (공정리스트 / T&C List / 지연 리스트 / 오늘의 주요작업)
- 표는 그대로 두되, 폰에서는 가로 스크롤 영역임을 알리는 좌우 스크롤 힌트와 상단 스크롤바를 유지.
- 첫 번째 식별 열(No. / Activity / Item)을 폰에서도 좌측 고정해 어떤 행인지 잃지 않도록 함.
- 검색·필터·내보내기 도구 줄을 폰에서 세로로 쌓고, 검색창은 전체 폭 사용.
- 활성 필터 칩 줄은 가로 스크롤 처리.

### 4) 대시보드 / 오늘의 주요작업 카드
- 카드 내부를 폰에서 위아래 배치(큰 숫자 위, 세부 표 아래)로 전환.
- 팀별/건물별 탭과 세부 표는 폰에서 글자·간격을 한 단계 축소.
- 마일스톤·KPI 카드 격자는 폰 1열, 태블릿 2열, 데스크톱 현행 유지.

### 5) 네트워크 / T&C Progress
- 네트워크 상세 패널: 폰에서는 하단 시트로 열리고 화면 높이의 약 85%까지, 상단에 닫기 버튼 고정.
- 네트워크 차트는 폰에서 "가로로 돌려서 보기" 안내와 확대/축소 버튼을 크게.
- T&C Progress 필터 줄은 폰에서 접이식(필터 열기/닫기)으로 정리하고, 매트릭스 고정 열 폭을 폰에서 축소.

### 6) 공통
- 버튼·아이콘 버튼 최소 터치 크기 확보(약 40px).
- 팝업/대화상자(내보내기, 업로드 확인 등)를 폰에서 전체 폭으로.
- 본문 좌우 여백을 폰에서 축소해 표시 폭 확보.

## 기술 메모

- `src/components/app-shell.tsx`: 모바일 서랍 메뉴(shadcn `Sheet`) 추가, 헤더 액션 `DropdownMenu`로 축약, 사이드바 브레이크포인트를 `sm` → `lg` 기준으로 재정의.
- `src/components/schedule-table.tsx`, `tc-view.tsx`, `tc.list.tsx`, `delays.tsx`, `today.tsx`: 툴바 `flex-col sm:flex-row`, 첫 열 `sticky left-0 z-10 bg-card`, 필터 칩 `overflow-x-auto`.
- `src/routes/_authenticated/dashboard.tsx`, `today.tsx`: 카드 내부 `grid-cols-1 sm:grid-cols-[1.15fr_1fr]`로 조정, 상위 격자에 `sm:grid-cols-2` 단계 추가.
- `src/components/network-view.tsx`: 상세 패널을 `inset-x-0 bottom-0 h-[85vh]` (모바일) / 기존 우측 고정(`lg:`)으로 분기.
- `src/routes/_authenticated/tc.progress.tsx`: 필터 영역 접이식 + 날짜 입력 `w-full sm:w-[140px]`.
- 검증: Playwright로 390px(폰)·768px(태블릿)·1280px(데스크톱) 스크린샷 비교, 가로 넘침 여부 확인.

## 범위 밖

데이터 로직, 계산식, 권한, DB 변경은 없습니다. 표시/레이아웃만 조정합니다.
