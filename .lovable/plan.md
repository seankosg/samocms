# 진행도 예측 요약 수치 시인성 개선

## 목표
현재 진행도 예측 차트 위에 한 줄로 나열된 요약 텍스트("실적 38.6% 계획 31.5% 격차 7.1%p 선행 …")를, 사용자가 한눈에 핵심 판단(선행/지연, 완료 전망)을 할 수 있도록 카드형 지표 블록으로 재구성한다. 그래프와 함께 직관적으로 읽히는 것이 목적.

## 대상 파일
- `src/components/dashboard/forecast-chart.tsx` — 요약 수치 영역(현재 318~339행) 재디자인. 공종별/마일스톤별/T&C 3개 모드 모두 이 요약을 공유하므로 한 곳만 고치면 전부 적용됨.

## 변경 내용

### 1. 요약 텍스트 → 지표 카드 그리드
한 줄 텍스트 나열을 5개의 미니 지표 카드로 바꾼다(모바일 2열 → 화면이 넓어지면 5열).

```text
┌─────────┬─────────┬──────────────┬──────────────┬────────────────────┐
│ 실적     │ 계획     │ 계획 대비     │ 최근 속도     │ 완료 전망           │
│ 38.6%   │ 31.5%   │ +7.1%p 선행  │ 3.3%p/일     │ 10.01 (53일 선행)  │
│         │         │              │ 최근 9개 기록 │ 계획 완료 11.23    │
└─────────┴─────────┴──────────────┴──────────────┴────────────────────┘
```

- **라벨은 작게(11px, muted), 값은 크게(18~20px, 굵게)** — 숫자가 먼저 눈에 들어오도록 대비 강조.
- **계획 대비 카드**: 선행이면 초록(`chart-2`), 지연이면 빨강(`destructive`) 계열 배경 틴트 + 아이콘(▲/▼) + "선행/지연" 뱃지를 붙여 색만으로 판단 가능하게.
- **완료 전망 카드**: 예측 완료일을 크게, 그 아래 작은 글씨로 "계획 완료 11.23 · 53일 선행/지연"을 표시. 예측 불가 시 기존처럼 경고 문구.
- **최근 속도 카드**: "3.3%p/일"을 크게, 보조 설명 "최근 N개 기록"은 아래 작은 글씨로 분리해 괄호 텍스트 혼잡 제거.
- 카드 스타일은 기존 대시보드 카드 톤(얇은 테두리·둥근 모서리·bg-card)에 맞추고, 시맨틱 토큰만 사용.

### 2. 그래프 연계 강화
- 완료 전망 카드의 날짜 표기를 차트의 예측/계획 완료 세로선 색상과 같은 색 계열(primary/foreground)로 맞춰 카드↔그래프 대응이 바로 보이게.
- 범례는 카드 아래에 유지하되 간격 정리.
