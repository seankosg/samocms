# Permit 담당자 미지정 75건 1회 등록

## 확인 결과
- 유첨 Excel의 입력 대상은 75건이며, Activity No. 빈 값과 중복은 없습니다.
- 현재 담당자 미지정 항목도 75건이며 모두 `Permit` 파일 소속입니다.
- Excel의 Activity No. 75개가 현재 미지정 항목 75개와 전부 1:1로 일치합니다.
- 이미 담당자가 지정된 항목을 덮어쓰는 경우와 현재 데이터에서 찾을 수 없는 번호는 없습니다.
- 입력 분포: 이희재 27건, 발주처 25건, 이승한 8건, 최원진 4건, 김두현 3건, 장건웅 2건, 최규산 2건, 한용태 2건, 황태언 2건입니다.

## 반영 방법
1. 유첨 파일의 `Activity No.`와 `담당자`를 고정 매핑한 1회성 데이터 변경을 만듭니다.
2. `source_file = Permit`, 숨김되지 않은 항목, 현재 담당자가 비어 있는 항목만 변경합니다.
3. Activity No.를 기준으로 75건의 `manager` 값을 입력합니다.
4. 이미 값이 있는 담당자는 변경하지 않아 예상치 못한 덮어쓰기를 방지합니다.
5. 변경 기록에는 유첨 파일 기준의 일회성 담당자 초기 등록임을 명시합니다.

## 재업로드 시 유지
- 현재 업로드 로직은 새 Permit 파일의 담당자 칸이 비어 있으면 기존 담당자를 보존하므로, 이번에 등록한 값은 이후 빈 담당자 파일을 올려도 유지됩니다.
- 이후 업로드 파일에 담당자 값이 명시되면 기존 원칙대로 파일 값이 우선합니다.

## 검증
- 변경 후 활성 Permit 항목의 담당자 미지정 건수가 0건인지 확인합니다.
- 75건 모두 유첨 Excel의 Activity No.–담당자 값과 일치하는지 대조합니다.
- 전체 담당자별 등록 건수가 Excel 분포와 일치하는지 확인합니다.
