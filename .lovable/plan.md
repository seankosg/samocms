# T&C 진행도 예측 탭 추가 (공종·건물별)

대시보드 예측 영역에 기존 「공종별 예측」, 「마일스톤별 예측」과 나란히 **「T&C 예측」** 상위 탭을 추가합니다. 시운전 단계별로 계획 대비 실적 곡선과 예측 완료일을 보여주고, 팀(Mech/Elec)과 건물로 나눠 볼 수 있게 합니다.

## 화면 구성

- 상위 탭: `공종별 예측` / `마일스톤별 예측` / `T&C 예측` (기존 두 탭 동작은 그대로 유지)
- T&C 예측 탭 안의 선택 순서
  1. 단계: `T0`, `T1`, `T2`, `Response`, 그리고 `전체(4단계 합산)` (Report·RFI는 제외)
  2. 팀: `전체`, `Mech`, `Elec`
  3. 건물: `전체` + 선택한 팀에 존재하는 건물 목록 (없는 건물은 표시하지 않음)
- 그래프는 기존 예측 차트와 동일한 형식
  - 계획 곡선(회색 실선), 실적 곡선(진한 파랑 실선), 예측 곡선(파란 점선)
  - 기준일 세로선, 계획 완료일 / 예측 완료일 세로선 + `선행 N일` / `지연 N일` 배지
  - 예측이 계획보다 늦은 구간 연한 붉은 음영, 빠른 구간 연한 초록 음영
- 요약: 현재 완료 건수·완료율, 계획 대비 격차, 최근 속도(건/일), 예측 완료일
- 요약표: 선택 조건 기준으로 건물별(또는 팀 전체 선택 시 팀별) 총 건수·완료·계획 완료일·예측 완료일·판정을 한 줄씩 표시하고, 행을 누르면 해당 조건이 적용된 T&C 리스트로 이동

## 계산 방식

- 데이터는 스냅샷이 아니라 **T&C 원본 항목의 계획일·실적일**을 직접 사용합니다. 날짜가 곧 기록이므로 하루도 빠짐없는 곡선을 그릴 수 있습니다.
  - 계획 곡선: 해당 날짜까지 계획일이 도래한 건수 누계 ÷ 전체 건수
  - 실적 곡선: 해당 날짜까지 실제 완료일이 찍힌 건수 누계 ÷ 전체 건수
  - `전체(4단계 합산)`은 4단계 각각을 한 건으로 세어 합산합니다.
- 단계가 해당 공종에 쓰이지 않는 경우(예: 전기의 Response 단계 기록이 거의 없음)에는 그래프 대신 "해당 단계 기록이 없습니다" 안내를 표시합니다.
- 속도: 최근 최대 14일 실적 누계에 최소자승 직선을 맞춰 하루당 완료 건수를 구합니다. 기록이 부족하면 처음~마지막 구간의 평균 속도를 사용합니다.
- 예측 완료일: 남은 건수 ÷ 속도. 상한 365일, 초과 시 `1년 이상`으로 표기하고, 속도가 0 이하이면 `현재 속도로는 완료 예측 불가`로 표시합니다.
- 계획 완료일: 계획 곡선이 100%에 도달하는 날짜.
- 어떤 원본 값도 수정하지 않습니다.

## 기술 사항

- 예측 계산은 이미 클라이언트에 있는 `tcItems`(단계별 계획일·실적일, 공종, 건물)로 수행하므로 **신규 서버 함수나 DB 변경이 필요하지 않습니다.**
- 신규 파일 `src/lib/tc-forecast.ts`: 단계·팀·건물 조건으로 일자별 계획/실적 누계 곡선, 속도, 예측 완료일을 계산하는 순수 함수.
- `src/components/dashboard/forecast-chart.tsx`에 `mode`를 `discipline | milestone | tc` 3종으로 확장하고, T&C 모드용 단계·팀·건물 선택 상태를 별도로 관리해 기존 탭 상태와 섞이지 않게 합니다. 곡선 렌더링·완료일 마커·툴팁은 기존 SVG 렌더 코드를 재사용합니다.
- 드릴다운은 기존 `/tc/list` 검색 파라미터(`disc`, `bldg`, `stage`, `field`) 규칙을 그대로 사용합니다.
- 검증: 타입 검사와 함께, 팀 전체 건수가 건물별 건수 합계와 일치하는지, 단계별 완료 건수가 T&C 화면의 완료 수치와 일치하는지 대조합니다.
