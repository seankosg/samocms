# 출면관리 탭 재구성 및 CMS 담당공종 확장

## 1. 출면관리 페이지 재구성

현재 2단계로 중첩된 「출면 업체 장소 관리 설정」 안의 회사·장소·별칭을 바깥으로 꺼내, 출면관리 페이지를 다음 네 개의 동등한 상위 탭으로 구성합니다.

1. 출면기록 관리자 설정
2. 출면업체 설정
3. 출면 장소 설정
4. 별칭 설정

- 주소의 `tab` 값도 `members`, `companies`, `locations`, `aliases`로 분리해 새로고침하거나 링크를 공유해도 선택 탭이 유지되게 합니다.
- 기존 사용자·업체·장소·별칭의 조회, 추가, 수정, 활성화, 정렬, 이름 변경, 삭제 제한 로직은 그대로 유지합니다.
- 중첩 탭만 제거하고 각 관리 내용을 독립 패널로 재사용하도록 정리합니다.
- 탭이 좁은 화면에서도 잘리지 않도록 가로 스크롤 가능한 탭 목록으로 구성합니다.

## 2. CMS 사용자 담당공종 7종 구성

담당공종 선택값을 다음 7가지로 확장합니다.

- 건축
- 전기
- 설비
- 공무
- 관리
- 안전
- 외부

사용자 답변에 따라 **사용자당 한 가지만 선택하는 풀다운**으로 변경합니다.

- 기존 사용자 목록의 여러 선택 버튼을 단일 선택 풀다운으로 교체합니다.
- 「새 계정 만들기」에도 담당공종 풀다운을 추가하고 선택값을 계정 생성 시 서버에 저장합니다.
- 서버 입력 검증도 7가지 중 최대 한 가지만 허용하도록 맞춥니다.
- 기존 `user_scopes` 저장 구조는 유지하되 사용자별 담당공종 행은 하나만 저장합니다.
- 기존 건축·전기·설비·공무 값은 현재 자료와 권한 동작을 유지합니다.
- 관리·안전·외부는 사용자 분류값으로 저장하며, 공정 수정 권한을 자동 부여하지 않습니다.

## 3. 지정 사용자 반영

현재 세 계정이 모두 존재하며 담당공종은 비어 있는 것을 확인했습니다. 다음과 같이 저장합니다.

- 김경섭: 관리
- 이정우: 안전
- 강기주: 외부

초기 명부의 동일 사용자 기본값도 함께 맞춰 향후 초기화·재구성 시 값이 달라지지 않게 합니다.

## 검증

- 네 개 출면관리 탭의 직접 진입, 새로고침, 각 추가·수정 화면을 확인합니다.
- 사용자 생성 시 선택한 담당공종 하나가 저장되고 목록에 동일하게 표시되는지 확인합니다.
- 지정된 세 사용자의 저장값을 데이터베이스에서 재확인합니다.
- 타입 검사와 화면 검증을 수행합니다.
