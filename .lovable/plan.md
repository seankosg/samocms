# 출면 화면 조별 집계·표시 개선 계획

## 목표
협력사 인원의 기본 해석은 주간 인원으로 유지하되, 사용자가 총계와 주간·연장·야간을 같은 화면에서 즉시 비교할 수 있도록 출면 현황, 검증 대조, 출면 추이, 메인 대시보드를 개선합니다.

## 1. 출면 현황
- 화면 제목 아래 설명의 전 조 총원 옆에 주간·연장·야간 인원을 같은 크기로 나란히 표시합니다.
- 협력사 × 장소 매트릭스의 두 번째 고정 영역을 단일 「계」 열에서 4개 열로 확장합니다.
  - 연인원: 주간+연장+야간
  - 주간
  - 연장
  - 야간
- 각 행과 최하단 합계행 모두 같은 4개 구성을 사용합니다.
- 매트릭스 Excel에도 동일한 4개 총계 열과 명칭을 반영하고, 고정 열 범위와 병합 헤더를 새 구조에 맞춥니다.

## 2. 검증 대조
- 4개 KPI 각각을 좌측 대표값과 우측 조별 수치 영역으로 재구성합니다.
- 대표값은 기존 전 조 기준을 유지하고, 오른쪽에는 주간·연장·야간별 값을 항상 모두 표시합니다.
- 각 조별 KPI는 기존과 동일한 계산식을 해당 조 데이터에만 적용합니다.
  - 검증 커버리지
  - 일치율
  - 평균 절대차
  - 미보고 발견
- 차이 추이 영역에 「전조·주간·연장·야간」 탭을 추가합니다.
- 선택한 조는 일별 차이·누적 차이와 협력사별 누적 차이 두 차트에 동시에 적용합니다.
- 표의 기존 조 필터, HSE/EXE 분리, Total 행과 내보내기 동작은 유지합니다.

## 3. 출면 추이
- 조 필터를 협력사별뿐 아니라 건물별·팀별 보기에서도 항상 사용할 수 있게 합니다. 기본값은 기존대로 주간입니다.
- 「연인원」 카드:
  - 큰 숫자는 현재 조 필터에 연동합니다.
  - 오른쪽에는 현재 선택한 협력사·건물·팀 범위의 주간·연장·야간 연인원을 항상 모두 표시합니다.
- 「근무일 평균」 카드를 「일일투입평균」으로 변경합니다.
  - 큰 숫자: 전 조 연인원 ÷ 실제 보고일 수
  - 오른쪽: 주간·연장·야간 연인원 ÷ 각 조의 실제 보고일 수
  - 실제 보고일은 해당 범위·조에서 협력사 보고 인원이 1명 이상인 날짜로 계산합니다.
- 「최대 투입일」 KPI는 현재 조 필터에 연동된 기존 동작을 유지합니다.
- 하단 연인원 표를 다음 열로 재구성합니다.
  - 총계 및 비중
  - 주간 및 비중
  - 연장 및 비중
  - 야간 및 비중
- 기존 「근무일 평균」 열은 숨깁니다.
- 총계와 각 조의 비중은 각각 같은 기준의 전체 합계를 분모로 계산합니다.
- 현재 Excel 내보내기는 일자별 당일 보고·재집계와 그룹별 연인원을 유지하되, 그룹별 시트에는 총계·주간·연장·야간 수치를 함께 포함합니다.

## 4. 메인 대시보드 오늘 출면
- 기존 전 조 합계 카드에 더해 주간·연장·야간 카드를 각각 생성해 총 4개 카드로 표시합니다.
- 네 카드 모두 같은 기준일과 협력사 보고 자료를 사용합니다.
- 각 숫자와 카드 제목은 출면 현황으로 이동하며, 조별 카드는 해당 조를 식별할 수 있는 검색값을 전달합니다.
- 보고 협력사, 준수율, 미보고 정보는 기존 전 조 합계 카드에 유지합니다.

## 공통 집계 원칙
- 조 구분은 현재 저장값을 그대로 사용합니다: `Day Shift`, `Overtime`, `Night Shift`.
- 조별 보조수치는 현재 선택된 협력사·건물·팀 범위를 따르되, 조 필터와 무관하게 세 조를 항상 모두 보여줍니다.
- 기존 HSE/EXE 검증 분리와 최신 재제출 우선 규칙은 변경하지 않습니다.
- 새 데이터 구조나 데이터베이스 변경 없이 현재 출면 자료의 화면 집계만 확장합니다.

## 확인
- 데스크톱과 모바일에서 카드·고정 열·가로 스크롤이 겹치지 않는지 확인합니다.
- 각 화면에서 총계가 주간+연장+야간과 일치하는지 검증합니다.
- 출면 추이의 협력사별·건물별·팀별 필터, 다중 선택, 조 필터 조합을 확인합니다.
- 검증 대조 차트의 네 탭과 두 차트가 동일한 조 조건으로 갱신되는지 확인합니다.
