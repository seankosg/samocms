# 공정표 업로드: 전체 교체 → 업데이트(병합) 방식 전환

확정된 규칙
- 항목 식별: Activity No 단독 (공종 파일 단위)
- 파일에서 사라진 항목: 삭제하지 않고 보관 후 숨김
- 화면에서 직접 고친 값: 업로드 파일 값이 우선
- T&C 업로드는 이번 범위에서 제외(다음 단계 검토)

확인된 현황: Activity No는 5개 공종 모두 빈 값 0건·중복 0건. 작업명은 중복이 많아 키로 쓰지 않습니다.

## 1. 업데이트 동작
- 파일에만 있는 번호: 새 항목으로 추가
- 양쪽에 있는 번호: 파일 값으로 갱신(작업명·건물·실·수량·진도·일정·선후행·협력사 등 전부 파일 우선)
  - 예외 1: 담당자 — 파일에 담당 열이 없거나 값이 비어 있으면 기존 담당자 유지(현재 동작 유지)
  - 예외 2: 숨김 상태였던 번호가 파일에 다시 나타나면 자동으로 숨김 해제
- DB에만 있는 번호: 숨김 처리(보관), 숨김 시각과 마지막으로 있었던 파일 기준일을 함께 기록

## 2. 중복 번호 처리 — 업로드 중 즉시 수정
- 파일 파싱 직후 같은 Activity No가 2번 이상 나오면 업로드를 멈추고 확인창을 띄웁니다.
- 확인창에는 중복 번호별로 해당 행들(작업명·건물·실)을 나란히 보여 주고, 각 행에 새 번호를 직접 입력할 수 있게 합니다.
- 번호가 비어 있는 행도 같은 창에서 번호를 입력하도록 요구합니다.
- 모든 충돌이 해소되어야 "적용" 버튼이 활성화됩니다. 수정한 번호는 이번 업로드에만 적용되며, 원본 엑셀을 고치라는 안내 문구를 함께 표시합니다.

## 3. 숨김 항목 표시 방식 (제안)
기본값으로 아래 A안을 적용하되, 선택지를 남겨 둡니다.

- A안(권장): 모든 화면의 기본 조회에서 숨김 항목을 제외합니다. 공정리스트 상단에 「숨김 항목 n건 보기」 토글을 두고, 켜면 해당 행이 회색 배경 + 취소선 + 「숨김」 배지로 표시되고 편집은 잠깁니다. 각 행에서 「되살리기」 버튼으로 복구할 수 있습니다.
- B안: 숨김 항목을 별도 페이지(예: 보관함)로 분리해 목록만 제공.
- 공통: 대시보드·진도율·지연·리포트·예측 등 모든 집계는 숨김 항목을 제외합니다.

## 4. 업로드 미리보기 확인창 확장
- 지금의 "행 수 차이"에 더해 신규 / 변경 / 숨김 예정 건수를 항목 단위로 표시합니다.
- 변경 항목은 바뀐 열만 "이전 → 이후" 형태로 최대 몇 건 예시로 보여 줍니다.
- 숨김 예정이 전체의 30% 이상이면 경고 문구와 함께 한 번 더 확인받습니다.
- 파일별 적용/건너뛰기 선택은 그대로 유지합니다.

## 5. 기준일·이력
- 이번 업로드에 포함된 모든 행의 기준일을 파일 기준일로 갱신합니다(숨김 항목은 유지).
- 항목별 스냅샷은 지금처럼 업로드 시점의 전체 현황을 남겨 진도율 추이의 연속성을 유지합니다. 숨김 항목은 스냅샷에서 제외합니다.
- 파일 기준일이 이미 반영된 최신 기준일보다 과거이면 경고하고 사용자 확인 후에만 적용합니다.

## 6. 안전장치
- 공종별 편집 권한 검사 유지.
- 한 번에 처리하여 중간 실패 시 부분 반영이 남지 않게 합니다.

## 기술 메모
- 마이그레이션: `activities`에 `(source_file, activity_no)` 유일 인덱스, `hidden_at timestamptz`(기본 NULL), `hidden_source_date date` 추가. 기존 행은 모두 표시 상태.
- 서버: `src/lib/activities.functions.ts`의 `importActivities`를 삭제+삽입 → `upsert(onConflict: source_file,activity_no)` + 미포함 번호 `hidden_at` 설정 + 재등장 시 `hidden_at = null`로 변경. 담당자 보존 로직은 유지.
- 클라이언트: `src/lib/import-schedule.ts`에 중복/빈 번호 검출 반환 추가, `src/routes/_authenticated/upload.tsx`에 번호 수정 확인창 + 확장된 미리보기 추가.
- 조회: `src/lib/use-project.ts`에서 기본적으로 `hidden_at is null`만 불러오고, 숨김 보기용 별도 조회를 추가. 숨김 해제용 서버 함수 1개 추가.
- 범위 밖: `importTcItems`(T&C)는 현행 유지.
