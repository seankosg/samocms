# 마일스톤별 진행도 예측 추가

가능합니다. 지금 공종별로만 되어 있는 대시보드 하단의 「공종별 진행도 예측」에 **공종별 / 마일스톤별** 전환 기능을 붙입니다. 계산 방식·그래프·요약표·드릴다운은 지금과 동일하게 유지하고, 묶는 기준만 마일스톤(M1~M8 등)으로 바꿉니다.

## 화면에서 달라지는 것

- 카드 제목 오른쪽에 「공종별 / 마일스톤별」 전환 버튼 추가.
- 마일스톤별을 고르면 탭이 M1, M2 … 로 바뀌고(자료에 있는 마일스톤만, 이름순), 「전체」 탭은 그대로.
- 그래프 구성은 동일: 계획 곡선, 실적 곡선, 예측 곡선, 기준일 선, 계획완료일·예측완료일 세로선, 선행/지연 배지.
- 아래 요약표도 선택한 기준에 맞춰 마일스톤별 행으로 바뀜(항목 수, 현재 실적, 계획완료, 예측완료, 차이).
- 마일스톤 값이 없는 항목은 「미지정」으로 한 줄 묶어 표시.
- 기존 규칙 유지: 담당이 HM(발주처)인 항목은 집계에서 제외하고, 발주처 계획완료일은 참고용 세로선으로 계속 표시.

## 기술 사항

- `src/lib/project.functions.ts`의 `getProgressForecast`: `activity_snapshots` 조회 컬럼에 `milestone`을 추가하고, 집계 키를 `discipline|snapshot_date`에서 `discipline|milestone|snapshot_date`로 확장. 반환 항목에 `ms` 필드를 추가(값 없으면 `미지정`). 기존 `disc` 필드는 유지하므로 공종별 화면은 그대로 동작.
- 마일스톤 표기는 `normMS`와 동일한 정규화(`M1` 형식)를 서버 집계에서 적용해 화면의 `Row.ms`와 키가 맞도록 함.
- `src/components/dashboard/forecast-chart.tsx`: `dim` 상태(`slot` | `ms`) 추가. 이력 집계 필터와 `sel` 행 필터, 탭 목록, 요약표 반복 대상만 `dim`에 따라 분기. 기울기 계산(`slopeOf`), 계획곡선(`planCurveOf`), 예측 종료일 계산 로직은 변경 없음.
- 드릴다운 링크는 마일스톤 선택 시 마일스톤 필터 조건으로 공정 리스트에 연결.
- 검증: `bunx tsgo --noEmit`, 마일스톤별 탭에서 항목 수 합계가 「전체」와 일치하는지 확인.
