# 안전리포트 영문 공정명 일관성 통일

## 확인 결과
현재 영문 안전리포트는 영문 AI 분석 결과를 별도로 저장하지만, 공정명은 「오늘의 주요작업」 영문 사전을 직접 읽지 않습니다. 따라서 AI 번역 표현이 화면의 공정명과 달라질 수 있습니다.

## 구현 내용
- 영문 안전분석 입력을 만들 때 「오늘의 주요작업」과 동일한 공정명 사전을 적용합니다.
- 수동 재분석과 매일 자동 생성 모두 언어별 입력을 따로 만들어 같은 기준을 사용합니다.
- 영문 안전리포트 화면, 인쇄본, 자동 생성 PDF가 동일한 저장 결과를 사용하도록 유지합니다.
- 기존 저장분은 그대로 두고, 해당 날짜를 `다시 분석`하면 새 통일 기준으로 갱신되도록 합니다.

## 검증
- 대표 공정명 `외벽 사이니지`가 영문 분석 입력에서 `Signage on External Wall`로 전달되는지 확인합니다.
- 타입 검사와 한국어/영문 생성 경로를 점검합니다.
