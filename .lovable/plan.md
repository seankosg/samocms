# SAMO 통합공정표 Raw Data + KPI 대시보드

업로드한 5개 공정표(건축·전기·기계·인테리어·인허가, 총 약 860건)를 하나의 데이터베이스로 통합하고, 진척 현황을 한눈에 보는 대시보드와 작업 목록 화면을 만듭니다. 기준일은 파일 상단에 표기된 2026-09-04입니다.

## 1) Raw Data 구축

Lovable Cloud 데이터베이스에 `activities` 테이블 하나를 만들고, 5개 파일의 행을 모두 적재합니다. 각 작업 행에 담기는 정보:

- 번호(No.), 공종(Arch / Elec / Mech / Int / MS·Gas)
- 건물(BodyShop, PaintShop, AssemblyShop 등 16개소), 실(Room)
- 공사범위(Work Scope), 마일스톤(M.1~M.7), 협력업체(Subcon), 작업명(Activity)
- 단위, 완료수량(Done), 전체수량(Total), 계획(%), 실적(%)
- 선·후행(Predecessor / Successor), 시작일, 종료일
- 원본 파일 구분(Arch/Elec/Int/Mech/Permit)

엑셀의 일자별 간트 막대 영역(8월~11월)은 시작일·종료일로 대체하여 저장합니다. 데이터는 마이그레이션에 INSERT 문으로 직접 포함해 첫 화면부터 실제 수치가 보이게 합니다. 읽기는 공개(익명 조회 허용), 수정은 차단합니다.

## 2) KPI 대시보드 (메인 화면)

상단 요약 카드
- 전체 진척률(실적 %) 및 계획 대비 차이
- 총 작업 수 / 완료 / 진행중 / 미착수
- 지연 작업 수(종료일 경과 & 실적 100% 미만)
- POP 관련 마일스톤 임박 건수

차트
- 공종별 진척률: 계획 vs 실적 막대 비교 (건축·전기·기계·인테리어·인허가)
- 건물별 진척 현황: 건물 16개소 완료율 가로 막대 + 잔여 물량 표기
- 마일스톤 M.1~M.7 현황: 마일스톤별 총건수/완료/지연 스택 막대
- 주간 종료 예정 물량 추이(기준일 이후 일정 분포)

지연·리스크 목록
- 기준일 대비 종료일이 지난 미완료 작업, 실적이 계획보다 크게 뒤처진 작업을 위험도 순으로 Top 리스트 표시(공종·건물·업체·잔여 수량 포함)

## 3) 작업 목록 화면

전체 작업 테이블 + 필터: 공종 / 건물 / 마일스톤 / 협력업체 / 상태(완료·진행·미착수·지연) 및 작업명 검색, 종료일·진척률 정렬. 각 행에 진척 바와 Done/Total 수량 표시.

## 디자인

건설 현장 관제 느낌의 다크 계열 대시보드, 상태색(정상/주의/지연)을 명확히 구분한 절제된 데이터 중심 UI. 한국어 표기 기준.

## 기술 메모

- Lovable Cloud 활성화 → `public.activities` 테이블 마이그레이션(GRANT + RLS: anon SELECT only) 및 시드 INSERT
- 엑셀 파싱은 사전에 수행하여 마이그레이션 SQL로 변환(엑셀 날짜 serial → date)
- 라우트: `/` 대시보드, `/activities` 작업 목록. 조회는 route loader + TanStack Query
- 차트는 recharts, 집계는 서버 함수 또는 클라이언트 집계(데이터량 소규모)
