# NCR Progress Row 진도율 바 및 전 항목 드릴다운

## 목표
- NCR 대시보드의 `Progress Start`와 `Progress Finish` 각 Stage 카드 하단에 계획·실제·차이를 한 줄 진도율 바로 표시합니다.
- 대시보드의 모든 항목명과 숫자를 클릭하면 그 수치를 구성하는 정확한 NCR 세부 목록으로 이동하게 합니다.

## Progress 카드 표시
- 각 PS별 Start/Finish 카드에서 현재 건수 표시는 유지합니다.
- 진도율 분모는 현재 대시보드 필터가 적용된 전체 대상 문서 수입니다.
  - 계획 진도율 = 기준일까지 계획일이 도래한 건수 ÷ 전체 대상 문서 수
  - 실제 진도율 = 실적일이 입력된 건수 ÷ 전체 대상 문서 수
  - 차이 = 실제 진도율 − 계획 진도율
- 카드 하단 한 줄에 계획 진도율은 회색, 실제 진도율은 검정 계열로 겹쳐 비교 가능한 바로 표현합니다.
- 차이가 음수이면 붉은색과 `-n%p`, 양수이면 초록색과 `+n%p`, 같으면 중립색 `0%p`로 표시합니다.
- 실제 값이 계획보다 큰 경우도 잘리지 않도록 각 비율은 전체 대상 기준 0~100% 범위에서 표시합니다.
- 밝은 화면과 어두운 화면 모두에서 회색 계획선, 실제선, 차이 수치가 구분되도록 기존 색상 체계를 확장합니다.

## 정확한 드릴다운
- 대시보드 필터(문서종류·팀·협력사)와 기준일을 목록으로 함께 전달합니다.
- NCR 목록 검색조건에 `Stage 슬롯`, `Start/Finish`, `계획/실제/차이/지연`, `기준일`을 추가하고 URL로 유지합니다.
- Progress의 계획 건수·계획 진도율 클릭: 해당 PS Start/Finish의 계획일이 기준일까지 도래한 문서만 표시합니다.
- 실제 건수·실제 진도율 클릭: 해당 PS Start/Finish의 실적일이 입력된 문서만 표시합니다.
- 음수 차이 클릭: 기준일까지 계획되었지만 실적이 없는 미달 문서만 표시합니다.
- 양수 차이 클릭: 기준일까지 계획 대상은 아니지만 실적이 입력된 초과 문서만 표시합니다.
- 지연 합계, Start 지연, Finish 지연은 각각 정확한 지연 문서만 표시합니다.
- 현재단계 PS1~PS9와 Closed는 현재처럼 자동 산출 단계 기준으로 표시하되, 대상 문서·종결 건수와 행 제목도 클릭 가능하게 만듭니다.
- PS 제목은 해당 PS와 관련된 문서 목록으로 이동하고, 목록 상단에 적용된 상세조건을 명확히 표시합니다.

## 구현 범위
- `src/routes/_authenticated/ncr.dashboard.tsx`: 진도율 계산, 한 줄 비교 바, 항목별 클릭 영역과 검색조건 전달
- `src/routes/_authenticated/ncr.index.tsx`: 상세 검색조건 검증·필터링, 드릴다운 조건 표시와 해제
- `src/styles.css`: 계획 회색, 실제 검정 계열, 미달 붉은색, 초과 초록색의 의미 기반 색상 토큰 보완

## 검증
- 임의의 PS Start/Finish에서 계획·실제·차이 비율을 원본 건수로 재계산해 일치 여부를 확인합니다.
- 각 숫자를 클릭한 목록 건수가 대시보드 숫자와 동일한지 확인합니다.
- 문서종류·팀·협력사 필터와 기준일을 바꾼 뒤에도 드릴다운 조건이 유지되는지 확인합니다.
- 797px 현재 화면과 데스크톱 화면에서 카드 내용 겹침, 가로 스크롤, 클릭 영역을 확인합니다.
