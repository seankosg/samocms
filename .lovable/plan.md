# 건물 별칭 표시 통합

## 변경 내용
- 원본 업로드 값과 데이터베이스 값은 수정하지 않습니다.
- 화면용 공정 데이터 변환 단계에서 공백·마침표·대소문자를 제거한 키로 별칭을 판정합니다.
- `C.C`와 `Consolidation Center`는 `C.C`로, `C.C.C`는 별도 `C.C.C`로 유지합니다.
- `M.G.`, `MG`, `Main Gate`는 `Main Gate`로 통합합니다.
- 공정리스트, 지연리스트, Progress, 네트워크, 대시보드 등 공통 변환 데이터를 쓰는 화면의 표시·필터·집계에 동일하게 적용합니다.

## 확인
- 타입 검사와 빌드 상태를 확인합니다.
- 대표 별칭이 지정한 표준명으로 변환되는지 검증합니다.
