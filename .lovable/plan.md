# NCR 대시보드 시인성 개선

## 목표
- 선택한 **Matrix data dashboard** 방향으로 NCR 대시보드를 재구성합니다.
- PS1~PS9를 같은 열축에 정렬해 단계 간 진행·지연·현재 건수를 빠르게 비교할 수 있게 합니다.
- 기존 필터, 기준일, 집계 기준, 카드 클릭 후 NCR 리스트 이동 기능은 유지합니다.

## 화면 구성
1. **상단 요약·필터**
   - 기준일, 문서종류, 팀, 협력사 필터를 한 영역에 정돈합니다.
   - 대상 건수와 종결 건수를 더 큰 숫자로 분리해 즉시 보이게 합니다.
   - 색상 범례를 표시합니다: 계획=파랑, 실적·완료=초록, 지연=빨강, 보조·0건=회색.

2. **공통 PS 열 머리글**
   - PS1~PS9와 각 단계명을 한 번만 표시하고, 아래 모든 행이 같은 열에 맞춰지도록 합니다.
   - 좁은 화면에서는 열을 찌그러뜨리지 않고 가로 스크롤로 비교 구조를 유지합니다.
   - 첫 번째 항목명 열은 고정해 스크롤 중에도 행 의미를 알 수 있게 합니다.

3. **Progress Stage**
   - Start와 Finish를 각각 한 행으로 분리합니다.
   - 각 PS 셀에 아래 정보를 함께 표시합니다.
     - 계획: `P 82건`
     - 실적: `A 64건`
     - 계획 대비 실적: `78%`
   - 달성률은 `실적 ÷ 계획 × 100`으로 계산하며, 계획이 0건이면 `—`로 표시합니다.
   - 100% 이상도 실제 값 그대로 표시해 초과 달성을 숨기지 않습니다.
   - 퍼센트와 얇은 진행 막대를 병행해 숫자와 시각 비교를 모두 제공합니다.

4. **지연 현황**
   - Start 지연과 Finish 지연을 각각 구분하고 합계도 명확히 표시합니다.
   - 지연이 있으면 빨간 강조, 0건이면 중립 회색으로 처리합니다.

5. **현재단계 현황**
   - PS1~PS9의 현재 체류 건수를 동일 열에 배치합니다.
   - Closed는 별도 완료 셀로 구분해 초록색으로 강조합니다.

## 디자인 적용
- 선택 색상: 밝은 바탕 + 파랑·초록·빨강의 신호등 대비 체계.
- 선택 글꼴: Outfit 제목, Figtree 본문·수치.
- NCR 전용 의미 색상을 전역 디자인 토큰으로 정의하고 화면에서는 해당 토큰만 사용합니다.
- 작은 글자와 잘린 단계명을 줄이고, 숫자 크기·굵기·여백을 높여 시인성을 확보합니다.
- 클릭 가능한 셀에는 짧은 테두리·배경 반응과 키보드 포커스를 제공합니다.

## 구현 범위
- `src/routes/_authenticated/ncr.dashboard.tsx`: 기존 카드 3행을 공통 열축 행렬 구조로 재구성하고 Start/Finish별 건수·달성률을 추가합니다.
- `src/styles.css`: Outfit/Figtree 및 NCR 상태용 의미 토큰을 추가하고 밝은 화면과 어두운 화면의 대비를 맞춥니다.
- 필요한 경우 작은 표시 단위를 NCR 대시보드 내부 전용 구성요소로 분리해 반복을 줄입니다.
- 데이터 저장 방식, 권한, 업로드, NCR 리스트의 편집 기능은 변경하지 않습니다.

## 검증
- 실제 관리자 데이터로 PS별 계획·실적 건수와 달성률 계산을 대조합니다.
- 각 셀을 눌렀을 때 기존 NCR 리스트 이동과 필터 전달이 유지되는지 확인합니다.
- 데스크톱 1440px와 현재 화면 폭 약 800px에서 글자 겹침, 잘림, 열 정렬, 가로 스크롤을 확인합니다.
- 밝은 화면과 어두운 화면에서 계획·실적·지연·0건 상태의 대비를 확인합니다.
