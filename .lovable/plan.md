# 일일 안전 리포트 텔레그램 발송 (Rev.4) — 작업 계획 (보완 반영)

승인된 계획에 요청하신 세 가지 보완을 반영했습니다. 세 가지 모두 타당해 그대로 채택합니다.

## 이번에 바뀐 부분

1. **공개 읽기 범위 확대** — `safety_tg_%` 뿐 아니라 `manpower_%` 설정 키도 비로그인(봇) 읽기를 엽니다. 봇이 출면 알림 설정도 읽어야 하므로 함께 여는 편이 맞습니다. 그 밖의 설정 키는 계속 비공개입니다.
2. **PDF 캐시 무효화** — 「다시 분석」으로 같은 파일명을 덮어쓰면 텔레그램이 옛 파일을 캐시할 수 있으므로, 뷰가 내주는 PDF 주소 끝에 `?v=<준비 시각>`을 붙입니다. 준비 시각이 바뀌면 봇·텔레그램이 항상 새 파일을 받습니다.
3. **본문은 읽는 시점에 완성** — 본문을 생성 시점에 고정하지 않고, 뷰가 **읽는 순간의 설정 본문**에 `{date}`를 채워 내줍니다. 설정에서 문구를 바꾸면 그날 발송분부터 즉시 반영됩니다. (인수 확인 3번도 "다음 생성분" → "즉시 반영"으로 바뀝니다.)

## 전체 작업 (승인본 유지 + 위 반영)

### 1) PDF 자동 생성
- 안전 리포트 한글·영문이 **둘 다 저장되는 순간** A4 PDF 2개를 서버에서 직접 만들어 공개 버킷에 저장(`safety/2026-09-12-ko.pdf`, `-en.pdf`).
- 이미지 캡처가 아니라 글자·표·선을 그리는 문서형 PDF. 구성·색은 화면 리포트와 동일.
- 「다시 분석」 시 다시 만들고 준비 시각을 갱신 → 주소의 `?v=` 값이 바뀌어 캐시 문제 없음.
- 화면의 기존 인쇄 버튼은 그대로 유지.

### 2) 「안전리포트 설정」 화면 (관리자 전용, 설정 섹션)
- 텔레그램 발송 사용(기본 꺼짐) / 발송 시각 05:00 / 재시도 종료 05:20 / 재시도 간격 5분
- 한글·영문 본문 편집(지시서 §2.3 기본 문구, `{date}` 자리표시자, 1,000자 제한)
- 결과 수신자: HDEC 회원 다중 선택(기본 이승한·이정우), 미등록자 저장 거부
- 최근 발송 결과 표 + 「오늘 리포트 재발송」 버튼(재발송 번호 +1)
- 「출면 업체 장소 관리 설정」의 **알림 설정 카드를 이 화면으로 이동**(저장 로직·키 그대로)

### 3) 새 화면 「Safety Report」 (리포트 섹션, Progress Report 바로 위)
- 독립 화면으로 안전 리포트 열람 · 한/영 전환 · 인쇄 · 날짜 선택 · PDF 내려받기
- 열람은 로그인 사용자 전체, 「다시 분석」은 관리자 전용

### 4) 봇 연계
- 공개 조회 뷰 `v_safety_telegram`: `day`, `pdf_ko_url`·`pdf_en_url`(`?v=준비시각` 포함), `cover_ko`·`cover_en`(읽는 시점 설정 + `{date}` 치환), `ready_at`, `send_seq`
- 원본 리포트 표는 계속 비공개, 뷰만 공개 읽기
- 봇의 `mode='safety'` 기록을 설정 화면 표에서 조회

## 기술 메모
- `safety_reports`에 `pdf_ko_path`, `pdf_en_path`, `telegram_ready_at`, `telegram_send_seq` 추가(본문 컬럼은 두지 않음 — 뷰에서 조립).
- 뷰에서 날짜 치환: 한글 `2026년 9월 12일 (토)`, 영문 `12 Sep 2026 (Sat)` 형식을 SQL에서 생성해 `replace(설정본문, '{date}', …)`.
- PDF: `pdf-lib` + `@pdf-lib/fontkit`, 한글 글꼴은 버킷에 올려 두고 런타임 fetch + 캐시.
- 생성: `src/lib/safety-pdf.server.ts` 신설, 자동 생성·「다시 분석」 양쪽에서 두 언어 완료 시 호출.
- `app_settings` 공개 읽기 정책: `key LIKE 'safety_tg_%' OR key LIKE 'manpower_%'` + GRANT SELECT TO anon.
- 뷰는 `security_invoker` 미사용, `GRANT SELECT ON v_safety_telegram TO anon`.
- 설정 저장은 기존 관리자 전용 서버 함수 패턴, 시각 정규화 재사용.
- cron: 안전 리포트 자동 생성을 03:00~04:50 15분 간격 + 05:00~09:00 30분 재시도로 조정.

## 인수 확인
1. 생성 후 뷰의 오늘 행에 PDF 2개 주소·본문 2개·준비 시각이 채워지고 로그아웃 상태에서 열림
2. 공개 키로 뷰 조회 가능, 원본 표 직접 조회는 거부
3. 설정에서 본문을 바꾸면 **즉시** 뷰의 본문에 반영, HDEC 미등록자는 수신자로 저장 불가
4. 「다시 분석」 후 PDF 주소의 `?v=` 값이 바뀜 / 재발송 버튼 → 회차 +1
5. 봇의 `mode='safety'` 기록이 설정 화면 표에 표시
