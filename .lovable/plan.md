# 대시보드 A4 PDF 리포트 출력

대시보드 우측 상단에 "PDF 리포트" 버튼을 추가하고, 누르면 A4 3페이지 구성의 인쇄 전용 리포트가 열려 그대로 PDF로 저장할 수 있게 합니다.

## 리포트 구성

**공통 머리말/꼬리말** — 프로젝트명, 기준일, 출력일시, 페이지 번호

**1페이지 · 대시보드 요약**
- 상단 KPI 카드 3장(총 활동 / 계획 대비 실적 / 지연)을 화면과 같은 카드 형태로 배치, 각 카드 오른쪽의 공종별 계획·실적·차이 표 포함
- MEP T&C 요약 카드
- M1~M8 마일스톤 표, 부서·건물·협력사 지연 상위 리스트는 화면과 동일한 리스트 형태 유지
- 색상·막대 그래프는 인쇄용으로 유지(배경색 인쇄 옵션 안내 포함)

**2페이지 · 지연 리스트 상세**
- 기준일 기준 지연 전체 건을 표로 출력 (건수에 따라 자동으로 여러 장으로 이어짐)
- 컬럼: No., 담당부서, 건물, Room, 협력사, 활동명, Milestone, 시작·종료(dd-mmm), 계획%, 실적%, 격차
- 격차가 큰 순으로 정렬, 표 머리행은 페이지마다 반복

**3페이지 · T&C 공종별(MECH / ELEC) T1·T2 현황**
- 공종별로 T1(Internal T&C)과 T2(Consultant Inspection) 단계의 총 수량, 완료, 잔여, 지연, 달성률 요약
- 그 아래 건물 × Item 단위 T1·T2 완료/잔여/지연 표
- Pass / Fail 집계 포함

## 기술 메모

- `src/routes/_authenticated/report.tsx` 신규 route 추가. 대시보드와 같은 `projectQuery` 로더/`useProject`를 사용해 동일한 수치 사용.
- 대시보드 계산 로직(KPI, 공종별 계획·실적, 마일스톤, 지연 랭킹)은 `src/lib/report-metrics.ts`로 추출해 대시보드와 리포트가 같은 계산을 공유. 대시보드 화면 결과값은 변경 없음.
- 리포트는 `AppShell` 없이 인쇄 전용 레이아웃(`@page { size: A4; margin: 10mm }`, `print-color-adjust: exact`)으로 렌더링하고, 페이지 경계는 `break-after: page` 로 고정.
- 화면 진입 시 상단에 "인쇄 / PDF 저장" 버튼을 두고 `window.print()` 호출. 별도 PDF 라이브러리 없이 브라우저 PDF 엔진 사용 → 텍스트 선택 가능, 표 정렬 깔끔.
- 대시보드 헤더 `actions`에 리포트 버튼(새 탭으로 `/report` 열기) 추가.
- T&C 집계는 기존 `stageProgress` / `buildBlocks`를 재사용하되 T1·T2 단계만 추출.
