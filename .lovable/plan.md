# 발주처 공정 리스트 — 표에 실제 담당부서 표시

## 목표
공정 표의 `담당부서` 칸을 별도 옵션·모드 없이 항상 실제 부서명으로 보여 줍니다. 발주처 행은 Paint·IT·HM·Secu·Ass'y·Glov·Body·MS가, 당사 행은 지금처럼 공종명(건축·전기 등)이 표시됩니다. 저장된 공정 값(HMMME)과 다른 화면의 로직은 그대로 둡니다.

## 방식 (옵션 없이 직접 표시)
공정 표 전체에서 담당부서 값 하나를 고르는 기준을 통일합니다: 실제 부서 값이 있으면 그것을, 없으면 기존 공종명을 씁니다. 당사 행은 실제 부서 값이 비어 있어 자동으로 기존 표시가 유지됩니다.

## 적용되는 곳 (같은 기준으로 일괄)
- 표의 담당부서 칸
- 담당부서 열 필터 목록과 건수
- 담당부서 정렬, 검색어 대상
- 엑셀보내기의 담당부서 열
- 상단 부서 탭 선택이 표 내부 필터와 같은 값으로 맞물림 (현재는 탭 값과 표 값이 어긋나 결과가 비는 문제 해결)

## 건드리지 않는 것
- 데이터베이스에 저장된 공정 구분(HMMME)과 `owner_dept` 값
- 발주처 권한 판정, 발주처 페이지 묶음 인식, 네트워크 보라색 표시
- 대시보드·예측·스냅샷 집계 로직
- 당사 공정 리스트 화면의 보이는 결과(실제 부서 값이 없으므로 동일)

## 기술 메모
- `src/components/schedule-table.tsx`: `deptLabel(r) = r.ownerDept ?? SLOT_LABEL[r.dept] ?? r.dept` 헬퍼 하나로 `multiValue("dept")`, 행 렌더(257행 부근), 검색 haystack, 정렬 키 `dept` 비교, 엑셀 행(165행)을 교체. `initial.dept` 초기화에서 owner 리스트에서 넘어오는 실제 부서명은 `SLOT_LABEL` 매핑 없이 그대로 넣도록 처리.
- `src/routes/_authenticated/owner.list.tsx`: 상단 탭 목록·필터는 이미 `r.ownerDept ?? r.dept` 기준이므로 유지.
- 검증: `bun x tsgo --noEmit` + Playwright로 `/owner/list` 부서 탭 클릭 시 행 수·담당부서 칸 확인, `/schedule`에서 당사 리스트 표시 변화 없음 확인.
