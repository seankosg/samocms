# 대시보드 KPI 카드 → 리스트 드릴다운

대시보드의 KPI 카드에서 숫자(왼쪽 큰 값)나 오른쪽 팀별 세부 항목을 클릭하면, 해당 조건이 이미 적용된 리스트 화면으로 바로 이동하도록 합니다.

## 클릭 → 이동 규칙

총 활동 카드
- 큰 숫자(총 활동) → 공정리스트 전체
- 완료 수치 → 공정리스트, 상태=완료
- 오른쪽 팀별 행: 계획 → 해당 공종 + 기준일 내 종료 예정, 실적 → 해당 공종 + 완료, 팀 이름 → 해당 공종 전체

계획 대비 실적 카드
- 큰 숫자 → 공정리스트 전체(진도 대상)
- 팀별 행 → 해당 공종 공정리스트

지연 카드
- 큰 숫자 → 지연 리스트 전체
- 팀별 지연 건수 → 지연 리스트, 해당 공종만

마일스톤 카드 (M1~M8)
- 총 건수 → 해당 마일스톤 공정리스트
- 지연/초과 → 해당 마일스톤 지연 리스트
- 계획/실적 행 → 해당 마일스톤 + 기준일 내 예정 / 완료

MEP T&C 카드
- 큰 숫자와 공종별 값 → T&C List로 이동, 해당 공종(MECH/ELEC) 필터 적용

부서별 진도표, 건물별·협력사별 지연 표의 각 행도 같은 방식으로 클릭 가능하게 합니다(건물/협력사는 해당 값으로 필터).

## 화면 동작

- 클릭 가능한 값은 마우스를 올리면 밑줄·색 강조와 커서 변경으로 표시하고, 키보드로도 이동할 수 있게 합니다.
- 리스트 화면은 진입 시 상단에 적용된 필터가 칩으로 표시되어, 사용자가 바로 해제하거나 조건을 바꿀 수 있습니다.
- 필터 조건은 주소(URL)에 담기므로 새로고침·공유해도 같은 결과가 유지됩니다.

## 기술 메모

- `/schedule`, `/delays`, `/tc/list` 라우트에 `validateSearch`로 검색 파라미터 추가: `slot`, `ms`, `bldg`, `sub`, `status`(done/ongoing/plan/delay), `duebyBase`(기준일 내 종료 예정), `q`.
- `ScheduleTable`에 `initial` prop을 추가해 최초 상태를 URL 값으로 세팅하고, 기준일 내 종료 예정 조건(`e <= base`)을 위한 선택적 필터 프롭 추가. 기존 기본 동작은 변경 없음.
- `tc-view` / T&C List에는 `discipline` 초기 필터만 연결.
- 대시보드 값들은 `Link`(TanStack Router)로 감싸며, 표시 로직·집계 계산식은 변경하지 않음. 프론트엔드 표현 레벨 작업만 수행.
