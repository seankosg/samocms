# 공정리스트 담당자 표시

업로드한 `★SAMO_통합공정표_20260911.xlsx`의 「담당」 값을 각 공정 항목에 고정하고, 공정리스트에 담당자 컬럼을 추가합니다.

## 확인된 내용

- 파일 맨 오른쪽(105번째 열)에 「담당」 컬럼이 있고, 881건에 값이 있으며 61건은 비어 있습니다.
- 값 분포: 최규산 312, 지브릴 146, 윤창선 122, 최원진 72, 김두현 64, 황태언 63, 장건웅 54, 한용태 42
- CMS 사용자 이름과 모두 일치하며, 「황태언」만 CMS의 「황태연」과 철자가 다릅니다 → 황태연으로 통일합니다.

## 할 일

1. **업로드 파일 인식 개선**
   - 현재 담당자 열 탐색이 왼쪽의 「담당부서」(공종) 열을 먼저 잡는 문제가 있어, 「담당부서 / Dept」는 제외하고 「담당 / 담당자 / Manager」만 인식하도록 수정합니다.
   - 앞으로 올리는 모든 공정표 파일에서 담당 컬럼이 있으면 자동으로 함께 저장됩니다.

2. **이름 통일**
   - 저장 시 이름 교정표를 적용합니다(황태언 → 황태연). 앞으로 새 불일치 이름이 생기면 추가만 하면 되도록 한 곳에 모아 둡니다.

3. **기존 데이터 반영**
   - 업로드한 20260911 파일 기준으로 현재 저장된 공정 항목의 담당자를 일괄 채웁니다(공종 + 공정번호 기준 매칭). 담당자 외의 값은 건드리지 않습니다.

4. **공정리스트 화면**
   - 「담당자」 컬럼을 추가하고, 값이 없으면 「미지정」으로 표시합니다.
   - 다른 컬럼과 동일하게 검색·값 선택 필터·정렬·컬럼 표시 설정·엑셀 내보내기에 포함합니다.

## 기술 메모

- `src/lib/import-schedule.ts`: 담당 열 탐색 정규식 수정(부서/Dept 제외), 이름 정규화 함수 추가.
- `activities.manager` 및 `activity_snapshots.manager` 컬럼은 이미 존재하므로 스키마 변경 없음.
- 기존 데이터 반영은 파싱 결과로 생성한 `UPDATE public.activities SET manager = ... WHERE discipline = ... AND activity_no = ...` 데이터 변경으로 처리.
- `src/components/schedule-table.tsx`: 컬럼 정의에 `manager` 추가(라벨 「담당자」, 빈값은 「미지정」), 필터·정렬·엑셀 컬럼 목록에 반영.
