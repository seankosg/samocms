# NCR 단계별 현황 색상 시인성 개선

## 목표
- NCR 대시보드의 **현재단계 현황** 행에서 건수가 많은 단계를 즉시 식별할 수 있도록 색상 강도를 적용합니다.
- 기존 PS1~PS9 및 Closed 클릭 이동, 필터, 집계 방식은 그대로 유지합니다.

## 화면 변경
1. **건수 기반 색상 강도**
   - 현재 필터 결과 안에서 PS1~PS9의 최대 건수를 기준으로 각 셀의 상대 강도를 계산합니다.
   - 0건은 중립 회색, 건수가 있는 셀은 연한 파랑부터 진한 파랑까지 단계적으로 표시합니다.
   - 가장 많은 단계는 가장 진한 배경과 높은 대비의 글자로 강조합니다.

2. **수치 가독성**
   - 건수 숫자를 현재보다 선명하게 표시하고, `건` 단위와의 위계를 유지합니다.
   - 배경이 진해질수록 글자색도 자동으로 밝게 전환해 대비를 확보합니다.
   - 선택 가능한 셀의 마우스 반응과 키보드 포커스를 색상 단계에 맞게 유지합니다.

3. **Closed 구분 유지**
   - Closed는 진행 중 단계와 혼동되지 않도록 기존 완료 의미의 초록색을 유지합니다.
   - PS1~PS9의 파란색 강도 체계와 시각적으로 분리합니다.

4. **범례 추가**
   - 현재단계 행에 `적음 → 많음` 색상 범례를 간결하게 추가합니다.
   - 색상만으로 의미를 판단하지 않아도 되도록 모든 셀의 실제 건수 표시는 유지합니다.

## 기술 사항
- NCR 전용 의미 색상 토큰을 사용하며 밝은 화면과 어두운 화면을 모두 지원합니다.
- 필터 변경 시 현재 보이는 데이터 기준으로 색상 강도를 다시 계산합니다.
- 고정된 열 너비와 가로 스크롤 구조는 변경하지 않습니다.

## 검증
- 0건, 최소 건수, 중간 건수, 최대 건수의 색상 차이와 글자 대비를 확인합니다.
- 문서종류·팀·협력사 필터 변경 후 색상 강도가 결과에 맞게 갱신되는지 확인합니다.
- PS 셀과 Closed 셀 클릭 시 기존 NCR 리스트 상세 연결이 유지되는지 확인합니다.
- 약 800px 화면과 데스크톱, 밝은 화면과 어두운 화면에서 겹침과 가독성을 확인합니다.
